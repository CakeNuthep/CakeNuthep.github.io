# Resume Game

A fun, interactive game about resumes, built using [Three.js](https://threejs.org/).
let try to play game at [`Resume Game`](https://cakenuthep.github.io/resume%20game/src/).

## About

This project is an experiment in showcasing resumes through a game experience. The main character is controlled in a 3D environment, with animations and sounds to enhance interactivity.

- **Technology:** Three.js
- **Language:** JavaScript (converted from TypeScript)

## Features

- Playable 3D character with movement controls
- Resume content presented in a game format
- Animations and sound effects
- No installation required—just open in your browser!

## Character Controls

The character controller is implemented in [`characterControls.js`](./characterControls.js).
